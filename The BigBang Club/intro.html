Web Development

Web developers build and maintain websites.

If you want to be a web developer, the work is typically very work focused and collaborating with a team that helps to coordinate the client's needs. The work could involve front-end, back-end, or full-stack web development.

Check out this wikipedia entry on web design.

The front end is what you see on the website, it includes presentation of content and user interface. The Front-end developers use HTML, CSS, javaScript and their relative frameworks to present the content effectively.

The back end is what hepls the application run. It stores and serves program data to ensure that front end has what it needs. Back-end developers use programming languages like Java, Python etc.

Full-stack developers are comfortable working with both the front and back ends. I will focus on full stack development.
